# Playtest notes — DrewCraft pre-V1 session

## Scope decisions (owner, 2026-09-15/16)

- **Aircraft-affected-by-weather DEMOTED to post-V1.** The
  aviation-weather bridge (MTS wind-frame coupling, turbulence,
  visibility effects on flight) is deferred. Flying still works;
  weather simply does not push planes around yet.
- **PROPOSED (not yet implemented): disable Project Atmosphere for
  pre-V1, keep Simple Clouds.** Rationale: PA + full storm simulation
  is too performance-heavy for the first playtest round. Simple Clouds
  stays for sky visuals only.
  - Consequences if adopted: no live storms, no handheld Weather Radar
    readings, no radar weather overlay, no weather-driven flak modifiers.
    Flak keeps working on altitude/distance math. The DrewCraft weather
    adapter is already fail-closed, so code needs no changes — only the
    pack (remove projectatmosphere + gaboulibs from the release set)
    and a fresh dev payload + Pages publish.
  - Decision needed before the session: run WITH PA (heavy but complete)
    or WITHOUT PA (light, weather items above skipped).
