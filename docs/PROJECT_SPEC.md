# DrewCraft Project Specification

## Product statement

DrewCraft V1 is a seamless multiplayer survival pack whose fun comes from exploring a striking large-scale world, traveling with vehicles and aircraft, building Create infrastructure, and raiding selected dungeons with friends.

## Design rules

- A stable, understandable game beats a larger speculative feature set.
- Geography matters; vehicles, aircraft, roads, and trains should be useful.
- Normal Minecraft survival remains recognizable and functional.
- Each major capability has one owner; avoid redundant systems and kitchen-sink additions.
- Client and server always share one exact release truth.
- Installation, launch, update, and repair should not require modpack expertise.

## V1 system ownership

| Capability | Owner |
| --- | --- |
| Overworld terrain and caves | Terrain Diffusion Plus |
| Offline/admin pregeneration | Chunky |
| Distant terrain | Distant Horizons |
| Industry, logistics, and trains | Create |
| Practical ground vehicles and aircraft | Immersive Vehicles/MTS |
| Engineered craft, ships, artillery, and firearms | Selected Create add-ons |
| Dungeon exploration | Five approved When Dungeons Arise structures |
| Ordinary survival ecology | Minecraft and selected upstream defaults |
| Release/update/deployment integration | DrewCraft tooling and integration mod |

## Non-goals for V1

Weather simulation, custom strategic populations, custom invasions/sieges/herds, Source Cores, and a bespoke endgame are not V1. Their preserved design is in `docs/FURTHER_IDEAS.md`.

## Acceptance direction

The product succeeds when friends can click the correct download, authenticate, launch, join the same server version, and enjoy a stable session containing the four pillars without manual pack work.
