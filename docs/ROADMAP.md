# DrewCraft Roadmap

## V1 — focused survival and exploration

1. Converge every build/release path on `v1_survival_exploration`.
2. Prove exact dependency resolution and a fresh/restarted dedicated server.
3. Test survival, vehicles, aircraft, Create, and an approved WDA dungeon.
4. Deploy and measure the multiplayer server; test backup and restore.
5. Pass Windows/macOS/Linux clean launcher and update acceptance.
6. Freeze, soak, promote, and tag `1.0.0`.

## V1.1 — polish from real play

- Fix observed performance, compatibility, UX, progression, recipe, vehicle, dungeon-density, and server-operation issues.
- Add no major system unless the V1 group clearly needs it.

## Later releases

- Weather, clouds, seasons, and aviation effects.
- Radar/weather coupling.
- Strategic sources, armies, sieges, herds, and a custom endgame.
- Additional curated content based on measured gaps.

See `docs/FURTHER_IDEAS.md` for the preserved design backlog.
