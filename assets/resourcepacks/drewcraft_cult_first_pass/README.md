# DrewCraft Covenant cult skins — first pass

This resource-pack source contains the first six DrewCraft Covenant/Illager Invasion recolors created for the endgame cult aesthetic.

Included entities:
- Basher / footman
- Archivist / cleric
- Inquisitor / heavy crusader
- Firecaller / prelate
- Necromancer / black priest
- Invoker / high inquisitor

Palette follows the canonical cult visual direction: charcoal/slate/warm stone/dark oak/aged ivory with oxblood and restrained old-gold accents.

## Important status

These are **first-pass 64x64 RGBA textures** placed at the expected Illager Invasion resource paths. Approved by the project owner for the first playtest (C1); final UV polish against every upstream model in the dev client remains post-playtest work. Adjust any model-specific regions/overlays in place rather than changing the resource paths.
